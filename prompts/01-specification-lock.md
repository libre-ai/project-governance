# Prompt — G1 Specification Lock

## Mission

Turn the accepted vision into implementation-complete specifications. Do not reopen Big Bang, Bun/React, Rust specialization, GitHub or delayed Clever provisioning.

## Required outputs

For every app/capability:

- user journeys and non-goals ;
- domain commands, queries, events and refusal cases ;
- canonical JSON Schema/OpenAPI/WIT contracts ;
- data model, ownership, retention and migration source ;
- authentication, Biscuit authorization and tenant facts ;
- Rust/TypeScript boundary ;
- accessibility and degraded-mode behavior ;
- unit/integration/contract/E2E/smoke tests ;
- work packages, owners and dependencies ;
- release and rollback criteria.

## Gate

Implementation agents encounter no unresolved cross-module architecture decision. Local library choices may remain only when they cannot alter contracts or repository boundaries.
