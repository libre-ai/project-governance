# Forge evidence — publiée par défaut

Évidence publique de la forge Libre AI (ADR-0009 §7, invariant I-20) : le journal des verdicts de gates et les rapports d'évidence signés. Tout est accessible anonymement ; rien ici n'est normatif (carte d'autorité : `docs/README.md`) — ce dossier **prouve**, il ne décide pas.

- `gate-acceptance-log.md` — journal public des verdicts : chaque gate franchie, sa décision, sa référence vérifiable (pull request, commit, candidat immuable).
- `YYYY-MM-DD-*.md` — rapports d'évidence datés, avec leurs empreintes.

Exception unique (I-20) : les détails exploitables d'une défense peuvent être résumés et hachés sur décision propriétaire ; la décision est alors journalisée ici même.

C'est le traceur public de la méthode : cette forge, gérant cette constellation, se documente elle-même.
